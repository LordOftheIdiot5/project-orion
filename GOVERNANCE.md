# Governance

Project Orion is intended to belong to no single corporation or government. This document describes how the project is governed today, and the direction we intend to grow.

## Current stage: Phase 0 (protocol design)

The project is currently in its earliest stage: an open protocol and reference architecture are being drafted publicly in this repository (see the [Whitepaper](WHITEPAPER.md)). At this stage:

- **Maintainers** review and merge pull requests, and triage issues.
- **Decisions** on protocol direction are made in the open, via GitHub issues and pull requests, so that reasoning and trade-offs are recorded for future contributors.
- Anyone may propose changes by opening an issue or pull request; see [CONTRIBUTING.md](CONTRIBUTING.md).

## Long-term intent: a multi-stakeholder foundation

As outlined in the Whitepaper, the long-term goal is for the core protocol, reference implementations, and safety specifications to be stewarded by a multi-stakeholder foundation, modeled loosely on standards bodies like the IETF, with representation from:

- AI & on-device ML engineers
- Privacy and cryptography experts
- Child psychologists and educators
- Rural telecom and connectivity practitioners
- Policy makers and NGOs

This structure does not exist yet. It will be proposed and refined in the open as the project matures past Phase 0, with input from the community.

## Decision-making principles

Regardless of how formal governance evolves, all decisions must remain compatible with the project's non-negotiable principles:

- Free forever — no paywalls, no ads, no data selling
- Private by default
- Works everywhere, including fully offline
- Never manipulates or addicts the user
- Fully open-source and auditable
- Culturally adaptive, never culturally imposing

## Changing this document

Proposed changes to governance should be opened as a pull request against this file so the rationale and discussion are preserved in the repository's history.
